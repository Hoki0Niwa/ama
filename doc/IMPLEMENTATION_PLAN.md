# 初回構築研究の実装計画

## 目標と現在地

`codex/fever-first40-benchmark` は初回本線1回の目標得点@40手を改善する研究ブランチ。ラフィーナ160,520点、ラフィソル166,840点を基準にする。対戦製品の13〜14連鎖安定目標と、研究の得点契約を区別する。

S0G（得点で可視発火し、必要資源のない局面でprobeを省く）を次の研究基準候補とする。62001〜62064の対応比較はB0 29/128、S0 43/128、S0G 44/128。研究の改善であり、Steamの実機成績・製品への採用ではない。

契約・APIは [ベンチマーク](FEVER_FIRST40_BENCHMARK.md)、測定条件・結果・限界は [研究結果](RESEARCH_RESULTS.md) を参照。既存B0/S0/native・設定・原データを凍結し、製品の新しい周期や操作制限を部分的に混ぜない。

## 次の工程：RL-P1

| 工程 | 作業 | 完了条件 |
| --- | --- | --- |
| RL-P1-0 | 独立環境・依存・CPU/GPU・元ソースの固定 | 推論／学習の動作確認と出所のhash |
| RL-P1-1 | 公開観測だけの環境adapter・合法配置・エンコーダ | 参照nativeとの遷移・得点・死亡・期限の一致、未来情報漏洩なし |
| RL-P1-2 | S0G教師の重複除去と配置模倣 | seed/episode単位の分割、失敗・不明終端を含むデータの検査 |
| RL-P1-3 | 同じ発火器F＋NNの判断 | Fの意味を保持し、B0構築だけを置換。費用を総250msへ含める |
| RL-P1-4 | 3runの小規模PPO | 各最大100万遷移、全runの学習曲線とcheckpoint |
| RL-P1-5 | S0G・BC+F・PPO+Fの対応評価 | 初回得点@30/35/40、全失敗、時間・CPU・メモリと採否を報告 |

詳細な実装責務・予算・評価群・停止条件は [SELFPLAY_RL_PLAN.md](SELFPLAY_RL_PLAN.md) を正本とする。RL-P1は未実装・未学習。リーグ自己対戦、大規模学習、製品統合は後続工程。

## 境界と残件

- 研究の色列はsplitmix4、可視3、標準周期の凍結モデル。mod周期と実時間の操作制約は別プロファイルで扱う。
- 実験は新規出力先へ保存し、途中で係数・予算・seed数を変えない。既知群を未知評価に流用しない。
- 完全Feverの自己対戦環境は別リポジトリ `C:/Users/ho_ki/git/fever-simulator` が所有する。接続時には観測、合法手、時間、報酬、タネ供給の整合を確認する。
- 製品のT13〜T16の校正・全キャラ受入れはこの研究の完了条件に混ぜず、製品ブランチで管理する。製品・Tsu・bridge・既定バイナリへの研究コード統合は行わない。
