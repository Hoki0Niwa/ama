# 仕様メモ・出典・未確定事項

更新：2026-10-05

対象：ぷよぷよeスポーツ（Steam版）のフィーバールール。段階Aではラフィーナの形状を用いた4色・単独連鎖構築のみを扱う。

## 1. 根拠の扱い

- **公式資料で確認**：メーカー・プラットフォームの説明または図から読める内容。
- **プレイヤー資料**：実機観察者の解説。作品・バージョンの違いに注意する。
- **試作上の仮定**：実装を限定するための選択であり、ゲームの確定仕様ではない。
- **未確認**：実機照合や追加調査が必要。

2026-10-01の調査では、puyo-camp・Puyo Nexus・Wikipediaへの直接アクセスが作業環境のネットワーク制限で遮断されたため、第6節の数値は検索エンジンの要約から得たものである。実装前に一次資料で再確認する。

## 2. 対象バージョン

ぷよぷよeスポーツ（Puyo Puyo Champions）Steam版を対象とする。既存のamaがこの版で動作しているため、連鎖倍率表もVer.2.02準拠のプレイヤー資料に合わせる。初代フィーバー、フィーバー2、15th、ぷよテトとは、タネ失敗時の減少量や倍率表に差があるので、他作品の資料を使う場合は版を明記する。

## 3. ツモの種類と回転

フィーバールールのツモは4種類ある。プレイヤー資料で確認。

| 種類 | 構成 | 回転 |
| --- | --- | --- |
| 2個組 | 2色または同色 | 軸ぷよを中心に回転 |
| 3個組 | 同色2個＋別色1個、または同色3個 | 軸ぷよを中心に回転 |
| 2色4個組（22ぷよ） | 2色2個ずつの2×2 | 軸なし。全体が回転し配色が回る |
| でかぷよ | 1色4個の2×2 | 回転しない。回転ボタンで色が変わる（正方向は赤→緑→青→黄） |

形状の並びはキャラ固有の16手周期（ドロップセット）で決まり、色だけが乱数で決まる。周期内のぷよ数はアルルの32からカーバンクルの48まで幅がある。登場キャラは24体（アルル、アミティ、りんご、ヘド、スルターナ、シェゾ、シグ、まぐろ、シエル、ホウライ、ルルー、ラフィーナ、すけとうだら、アリィ、ラグナス、りすくま、ドラコ、ウィッチ、ハーピー、セリリ、カーバンクル、サタン、ハルトマン、アレックス）に、Ver.2.02 で追加された隠しキャラ2体（ラフィソル、パプリス）を加えた26体。でかぷよは着地すると4セルに分かれ、以後は通常のぷよとして扱う。

`A`・`B`は色、`.`は空き。図は上段から下段の順。

```text
2個組   縦3個組  横3個組  2色4個組  でかぷよ
 B       A.       B.       AB        CC
 A       AB       AA       AB        CC
```

- 2個組：下側を軸として回転する。
- 縦3個組：左下を軸に、軸と上が同色、右がもう一色。
- 横3個組：左下を軸に、軸と右が同色、上がもう一色。
- 2色4個組：四角の中心で回転し、配色が回る。
- 着地後は、特殊ツモもセルごとに重力を適用する。

3・4個組の存在とでかぷよの色変更・分離は[公式マニュアル](https://manual.sega.jp/puyopuyo_esports/?pid=7)で確認。詳細な回転や配色は[プレイヤーによる基本仕様](https://puyo-camp.jp/posts/86313)を参照。軸位置まで明示する資料として[旧作の組ぷよ基本操作](https://www.ne.jp/asahi/root/inoue/103.htm)があるが、旧作資料をそのままSteam版の完全仕様と扱わない。

## 5. 盤面ルール

- 同色4個以上が縦横に接続すると消える。
- 消去後に落下し、再び消去が起きれば連鎖する。
- 敗北判定は左から3列目または4列目の12段目にぷよが置かれたとき。通の「3列目のみ」と異なる。プレイヤー資料で確認。中央の×表示は[通の公式説明](https://manual.sega.jp/puyopuyo_esports/?pid=4)と[フィーバーの公式説明](https://manual.sega.jp/puyopuyo_esports/?pid=7)で異なる。
- T2の遷移順は設置・ちぎり・14段目消滅→連鎖解決→敗北判定。連鎖後に中央12段目が空けば生存するモデルとし、テストする。
- 14段目に置いたぷよは消滅する（2026-10-04ユーザー指示）。Tsuの14段目占有と分離して扱う。ちぎり前後の消滅タイミングはユーザーも未確認なので、既定は試作上の仮定としてちぎり後。比較用のちぎり前モデルも用意し、実機確認後に確定する。詳細は [FEVER_PHYSICS.md](FEVER_PHYSICS.md)。
- 全消しは盤面が空になる現象として扱う。段階Aではタネや時間の報酬を付けない。

## 6. フィーバールールの仕様

段階B以降で使う。すべてプレイヤー資料と公式説明の要約に基づく。

2026-10-05追記：本節は旧調査の照合候補を含む。とくにレート、時計、タネ、攻撃・相殺のイベント順を、Steam版で実測した確定仕様と扱わない。[BATTLE_ROADMAP.md](BATTLE_ROADMAP.md) のT9で通常盤面の仕様を整理し、T14でフィーバーモードの値・順序を確定する。

### 6.1 連続相殺とフィーバーゲージ

開発の第1段階は、ユーザー指定により両者の相殺時のゲージ増加を0、初期ゲージを0として、フィーバー突入のない対戦を完成させる（T13）。これは検証用の設定であり、標準ルールのゲージ仕様を変更したという意味ではない。特殊ツモ・通常倍率・攻撃・連続相殺・落下は維持する。実機で設定・維持する方法はT10で確認し、AIが0と見なすだけでは達成扱いにしない。通常時の全消し効果も残る範囲をT9で照合する。標準ゲージによる突入・時計・タネ・復帰への対応はT14以降に行う。

- 予告おじゃまがある状態で連鎖を起こすと、長さにかかわらず落下が止まり、相殺した側のゲージが1増える。
- 消さずに置いた時点で予告おじゃまが落ちる。
- ゲージは7で満タンになりフィーバーに突入する。フィーバー終了時に0へ戻る。

### 6.2 フィーバータイム

| 事象 | 変化 |
| --- | --- |
| 初期値 | 15秒 |
| 上限 | 30秒 |
| 自分の攻撃が1連鎖ぶん相殺された | +1秒（相殺された側） |
| 通常時の全消し | +5秒。あわせて4連鎖相当のタネが降る |
| フィーバー中の連鎖終了 | 3連鎖で+0.5秒、以降1連鎖増えるごとに+0.5秒 |
| フィーバー中の全消し | +5秒。次のタネが+2連鎖 |

### 6.3 連鎖のタネ

- 大きさは3〜15連鎖。初回フィーバーは5連鎖。全消しと同時に突入した場合は7連鎖から始まる。
- フィーバー中に1回でも消すと、結果にかかわらず盤面が消えて次のタネが降る。
- 成功（実行連鎖数がタネの連鎖数以上）：次のタネは実行連鎖数+1。上限15。
- 失敗：puyo-campの資料では-2連鎖、Puyo Nexusの資料では「消した数より1少ない」とあり、**未確認**。
- タネの大きさは次回のフィーバーに引き継がれる。
- タネの盤面はキャラごとに用意されているとされるが、具体的な盤面データは**未確認**。

### 6.4 おじゃまぷよ

- 突入前に予告にあったおじゃまは保留され、フィーバー終了後に元の盤面へ落ちる。
- フィーバー中に撃たれたおじゃまはフィーバー側の予告に入り、相殺しない限りフィーバー中に落ちる。
- フィーバー中でも窒息負けはある。
- フィーバー終了後は元の盤面が復元される。

### 6.5 得点とおじゃまレート

- 得点式は通と同じ「消去数×（連鎖倍率＋連結ボーナス＋色ボーナス）×10」。
- おじゃまレートは、2026-10-05のユーザー指定に従い、フィーバールールの開始時120を開発基準とする。旧調査の「通常時70、フィーバー中120」は未照合の記載として撤回する。通常盤面／フィーバー盤面の扱いと時間経過による変化はT9でSteam版と照合する。
- マージンタイムの旧記載128秒は撤回。[SEGAの1.02更新告知](https://puyo.sega.jp/portal/topics/info/20181217_001796/)ではPS4／Switch版のフィーバー初期値は192。ローカルSteam版と時間経過によるレート変化は未照合。
- 連鎖倍率は通常盤面もフィーバー盤面もキャラごとに別テーブルで、上限999。例としてアミティの通常盤面は2連鎖8、3連鎖17、4連鎖22と報告されているが、表全体は[Ver.2.02の調査](https://puyo-camp.jp/posts/67754)から転記して確認する。

### 6.6 全消し

通の+30個ではなく、4連鎖相当のタネが降り、フィーバータイムが+5秒される。

## 7. 情報と色列

- AIへ渡す確定情報：盤面、現在のツモ、NEXT2個、形状周期の位置。
- それより先：形状は周期で確定するが、色は未知。
- 探索用の未来サンプルと、評価に使用する実際の色列は別の乱数状態とする。
- 最初の色列モデルは実装前に選び、記録する。4色の独立乱数を選んだ場合は、そのモデルの性能として報告する。
- プレイヤー資料によると、Steam版の色生成は色1つにつき乱数を1回消費し、初手に色の制約があり、3個組の色の決まる順序と、2色4個組で2色目が1色目と一致した場合の置換規則がある。詳細は[フィーバーのツモ生成法則](https://puyo-camp.jp/posts/69592)を参照し、再現する場合は照合する。周期が正しくても色列まで完全再現したことにはならない。
- 2色4個組では2色が異なる条件を明示する。3個組の全同色は許容する。

## 8. 未確定事項と初期対応案

| 項目 | 現状 | 初期方針 |
| --- | --- | --- |
| 壁蹴り・床蹴り・特殊な回転 | Steam版で未照合 | 保守的に省略し、対応配置が限定されると明記 |
| 3個組の L/J と縦横の対応 | T1で公式アミティ・ラフィーナ図と公開キャラ選択画面を照合し、L=縦、J=横と対応づけた | `dropset::decode()` に集約。Steam実機での全キャラ照合はT7。ドラコの手11/12/14/15=縦/横/横/縦はユーザー確認済み |
| 周期の開始位置とフィーバー突入・終了時のリセット | 開始は1手目（T7で隠し2キャラを実プレイで確認）。リセットなし（2026-10-04にユーザーが確認） | 周期位置は対戦開始からの通算手数で決める。フィーバー中の手も同じ周期を進める（ユーザーが確認） |
| 2列幅ツモの出現位置と3個組の出現時の向き | 未確認 | 3〜4列目に出現、3個組は軸が3列目と仮定 |
| 接地猶予・入力速度・重力のフレーム | 未照合 | 段階Aでは実時間を扱わない。段階Bで実機を計測して表にする |
| 連鎖のリンクごとの消去・落下フレーム、ちぎりの落下待ち、タネ落下演出 | 未計測 | 段階Bで計測し、唯一の時間単位をフレームに統一する |
| 隠れた段・上端の色保持 | 13段目保持・14段目消滅をT2で実装。14段目消滅はユーザー確認済み、ちぎり前後のタイミングは未確認 | ちぎり後を既定の仮定とし、ちぎり前の比較モデルも用意。15段目の操作上限は実機照合待ち |
| ちぎりと消去開始の細かな順序 | 実機で未照合 | 完全に落ち着いてから消去するモデルの妥当性を確認 |
| 敗北判定のタイミング | 中央2列は確認、細かな順序は未確定 | 配置・消去との順序を仕様として確定し検証 |
| 色列の乱数生成 | Steam版の完全再現なし。T3で4色独立乱数（splitmix64）の試作用モデルを実装 | モデルは [FEVER_ENGINE.md](FEVER_ENGINE.md) 第2節。計測結果はこのモデルでの値として報告 |
| タネ失敗時の減少量 | 資料間で-1と-2が食い違う | 実機で確認するまでパラメータ化する |
| タネの盤面データ | キャラ別とされるが未入手 | 実機から採取するか、汎用タネで代用して明記 |
| フィーバー側予告の落下タイミング | 「相殺しない限り落ちる」までは確認 | 次の設置時に落ちる前提で実装し、実機で照合 |
| キャラ別倍率表 | 2026-10-05に通常盤面の全26キャラ・19リンクをVer.2.02の調査から転記。ローカルSteam未照合 | `data/fever/scoring.json` と [FEVER_BATTLE_RULES.md](FEVER_BATTLE_RULES.md) に出典・試作計算・確認状態を記録。フィーバー盤面はT14 |

2026-10-05のT14追記：ユーザー指定の[なもこ氏のサイト](http://namob.net/puyof/)から基本仕様・タネ一覧・戦術記事を調査した。上表の旧「タネ失敗時の減少量」は、[本人の基本仕様](https://puyo-camp.jp/posts/86313)を根拠に差1／2／3以上を据置き／1減／2減へ分けた試作モデルを採用する。全26キャラのフィーバー倍率1〜17リンクを既存の測定表から追加した。タネは公開参照50盤面を取り込み、画像のみの2盤面は推測せず未収録。これらをローカルSteamの照合済み仕様へ昇格しない。時計停止・突入／終了演出の時間は明示観測イベントで扱い、通常盤面の校正値をフィーバー実測と呼ばない。[T14の仕様と確認状態](FEVER_MODE_ENGINE.md)。
