# R1：根の候補評価の再現契約

入口は `tools/evaluate_fever_first40_roots.py`。保存された公開観測で根の配置候補を選び、その先を同じB0で継続する条件付き比較。空盤面から動く新しい構築器の性能評価ではない。

## 入力と評価

固定 `selection.json` と診断データをツールが保持するSHA256で照合する。ローカルbaselineに入力がなければ復元・照合し、別の保存局面で置き換えない。

候補は同じ公開盤面・可視3から生成する。環境が所有する未観測の未来をActorへ渡さない。選択用と確認用の条件付き未来を分け、候補選択を確認結果でやり直さない。各確認側の未来は4本。幅250・深さ8・仮想6列・最大6threadを共通とする。

最初の実10以上を境界に、15以上をP15成功、10〜14を失敗とする。期限は絶対40設置で、保存局面からの残り手数を使う。整理で時計を戻さず、全失敗を分母へ含める。得点再採点は別の診断で、元の選択や採否を変更しない。

採否は完了、十分な切替局面、確認側の純改善、補助指標の非悪化をツールの `analyze` が検査する。通過しても軽量なオンライン方式の設計へ進む条件に限る。局面別gain/loss・クラスタ区間・全手順・資源・出所を保存する。[結果](../RESEARCH_RESULTS.md)。
