# S0G：公開資源によるprobe省略の比較契約

入口は `tools/bench_fever_firstscore40_s0_mass_gate.py`。設定は `data/fever/research/firstscore40_s0_mass_gate_v1.json`。B0/S0/S0Gを同時期・同seedで比較し、総予算と基準構築を変えない。

## 契約と方式

成功・終端は [得点契約](../FEVER_FIRST40_BENCHMARK.md)。最初の実10以上の単発得点が40手以内にキャラのTへ届けば成功。死亡・配置不能・timeout・エラー・未発火を除外しない。

S0Gは盤面のRYGB個数＋期限内の可視 `min(3,40-t)` Piece個数が40未満ならprobeを省き、同じB0へ進む。40以上は同じS0へ委譲。不正形式や未検証入力は元の検査へ委譲する。省略はcomplete=null・実probe時間null・追加遷移0で記録する。

62001〜62064、各キャラ64、3方式の384試行。可視3、幅250・深さ8・仮想6、最大6thread、総250ms・probe25ms/16000遷移。逐次実行し、キャラ順を交互、方式順は6順列で循環。主比較中にsource・設定・予算・標本数を変えない。全体wall上限60分。

## 前提確認と採否

公開5411観測の意味的一致、保存Fの保持、既知4timeout観測×3方式×20反復、既知8組×3方式のsmokeを主比較と分ける。既知群を新しい成功率の分母へ加算しない。

主対比はS0G−B0。全失敗を含む純改善、seedクラスタ区間、@30/@35、F期限と遷移、相対CPU/P95をツールの `gate()` と設定で評価する。S0Cのloss0／両方式timeout0は継承せず、失敗込みの純効果で研究継続を判断する。S0G−S0は効果保持と費用削減の補助比較。

全結果・全steps・失敗・反例・F監査・raw・依存hashを保存し、独立auditを行う。S0Cの保存仕様・gate・rawを変更しない。研究基準候補への昇格と製品採用を区別する。[結果](../RESEARCH_RESULTS.md)。
