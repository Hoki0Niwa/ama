## 現在の方針

amaを土台に、ぷよぷよeスポーツのフィーバールールで戦えるAIを作る。全体のロードマップは次の5段階で、現在は段階Aの計画整備の途中。Fever固有機能の実装は未開始で、2026-10-04に共通Ama基盤の速度改善を適用した。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| A | ラフィーナの特殊ツモで単独の大連鎖を組む（とこぷよ） | 計画整備中 |
| B | フレーム単位の時間モデルを導入する | 未着手 |
| C | フィーバー中の連鎖のタネを発火するソルバーを作る | 未着手 |
| D | ゲージ・タイム・連続相殺を含む対戦戦略を作る。自己対戦による調整を併用する | 未着手 |
| E | 形状別の入力経路とクライアント接続 | 未着手 |

段階Aを先に置く理由は、ツモ形状の抽象化と死亡判定の変更がコア全体に及び、他のすべての段階の前提になるためである。段階Aの範囲では、フィーバーのゲージ・時間・タネ・対戦処理を扱わない。
