# 36組までの確定ツモ・探索深さ比較（2026-10-05）

既知ツモ数と探索深さを同時に16・24・36組へ増やし、点数と計算時間を測定した。
組数には手持ちを含む（36組＝手持ち＋先の35組）。実際の未来の順番を渡す理想条件であり、
256個の色の内訳から順番を予測する精度の実験ではない。

## 条件

- 同じseed 0〜9の10試行ずつ、相手なし、最大100手。前回の40試行から減らした。
- 幅250、発火トリガー130,000、到達率ランキング無効。
- `config.json` のbuild重みを使用し、`clear_cost=0`、`score=400`、`form=0`。
- 既知ツモ数＝最大探索深さとし、全条件とも1本の確定キューをビーム探索する。
- 探索中にいずれかの初手候補で13万点以上を見つけると早期終了する。
  設定した深さは上限であり、常にそこまで展開するわけではない。
- 盤面74個以上で10,000点以上を発火する緊急ポリシーを含む既存ポリシーを使用。
- ベンチは最初の78,000点以上の連鎖で終了。13万・15万到達はその実得点から集計。
- 未発火は平均得点に0点で含め、単発消し回数と手数にも含める。
- 条件・シードともに1試行ずつ単独実行（`--jobs 1`）。ベンチと同時のビルド・テストなし。

点数と単発消しは各10ゲームの平均。1手の計算時間の概算はゲーム実時間合計を手数合計で
割った値で、盤面操作や診断も含み、通信・入力時間は含まない。最大1手は探索・発火判定の
実測値。条件ごとに盤面の進み方が変わるため、同一盤面での純粋な処理量比較ではない。

通常のエンジンの設定は変更していない。既にビルド・検証した `bin/bench/bench.exe` を使用し、
使用バイナリのSHA-256、条件、重みを各条件の `manifest.json` に記録。
`next-N.tsv` に原データ、`next-N-fields.txt` に終了盤面、`summary.json` に集計を保存。

## 再現

```powershell
.\build.ps1 -Target bench
foreach ($taskDepth in @(16, 24, 36)) {
    python bench/measure_next.py --exe bin/bench/bench.exe --output "docs/benchmarks/next36-new-run/next36-depth-$taskDepth" --next-counts $taskDepth --depth $taskDepth --seeds 10 --jobs 1
    if ($LASTEXITCODE -ne 0) { throw "NEXT benchmark failed for depth $taskDepth" }
}
```

前回の [深さ16固定のNEXT比較](../next-count-20261005/README.md) は40シード。
今回の16組条件も10シードで再測定し、過去の40試行平均を比較表へ混ぜていない。

## 結果

| 既知組数 / 最大深さ | 平均得点 | 13万以上 | 15万以上 | 未発火 | 単発消し/試行 | 小消し全体/試行 | 平均手数 | 1手の時間概算 | 最大1手 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 16 / 16 | 133,458 | 8/10 | 1/10 | 0/10 | 1.500 | 1.800 | 41.8 | 94.8ms | 225ms |
| 24 / 24 | 136,477 | 9/10 | 2/10 | 0/10 | 1.100 | 1.500 | 42.2 | 118.4ms | 316ms |
| 36 / 36 | 138,571 | 10/10 | 1/10 | 0/10 | 0.700 | 1.000 | 39.9 | 138.5ms | 435ms |

36組・深さ36は、16組・深さ16と比べて平均得点が5,113点高く、今回の10シードでは
すべて13万に到達した。単発消しは平均1.5回から0.7回へ約53%減った。
ただし15万到達は1/10で、24組の2/10を上回っておらず、毎回15万になる結果ではない。
13万発火ポリシーを使うため、15万を優先する別ポリシーの限界を示す実験でもない。

時間は16組から36組で1手平均が約1.46倍へ増えた。最も長い手は225msから435msへ増え、
平均時間に比べて長い手もある。幅250で展開数が制限され、13万を見つけた時点で早期終了する
現在の実装では、今回の範囲で時間が急増する結果にはならなかった。
実ゲームの通信・入力・プリフェッチを含む締め切り内の動作や、他の幅・発火トリガーは未検証。

計測合計は16組39,607ms/418手、24組49,985ms/422手、36組55,245ms/399手。
全30試行のシード・19列形式・重み・バイナリ・発火ポリシーの一致を確認した。
`bench/measure_next.py` は計測時間の集計を追加し、Pythonの構文チェックを通した。
今回のエンジンコード・通常設定の変更はない。

**少数シードでの比較であり、36組なら常に13万以上になるという保証ではない。**
未使用シードでの確認はしていない。点数・時間の集計はこのフォルダーの `summary.json` にも保存。
