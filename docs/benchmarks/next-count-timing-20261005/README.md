# 確定NEXT数の時間比較

[40シードの主比較](../next-count-20261005/README.md)と同じバイナリ・重み・幅250・実深さ16・
13万発火を使用し、seed 0〜2 を `--jobs 1` で単独実行した。
ベンチ以外のビルド・テストは完了させてから実行した。

`timing.json` は各TSVのゲーム実時間（8列目）合計を手数（6列目）合計で割った概算と、
1手の計算時間（9列目）の最大値を記録。平均の概算には盤面操作・診断も含む。
通信・入力時間は含まない。各条件で進む盤面が違う3シードの比較であり、
同一盤面の処理時間や実機の締め切りに間に合うことを保証する測定ではない。

| 既知組数（手持ち含む） | 1手の概算 | 最大1手 |
|---|---:|---:|
| 3 | 161.4ms | 350ms |
| 6 | 155.1ms | 364ms |
| 12 | 145.7ms | 284ms |
| 16 | 115.2ms | 224ms |

実時間と手数は `next-N.tsv`、終了盤面は `next-N-fields.txt`、バイナリSHA-256と
実験条件は `manifest.json`、得点・単発消しの集計は `summary.json` に保存。
